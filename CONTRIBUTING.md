# Contributing

Contributions are welcome while the project is experimental.

1. Discuss substantial product or compatibility changes in an issue first.
2. Keep each plugin independently installable.
3. Preserve local-first defaults and add no telemetry without an explicit design review.
4. Add tests for behavior changes and run `pnpm check` plus `pnpm pack:check`.
5. Do not commit private research data, databases, reports, tokens, cookies, or sessions.
6. Record copied or adapted third-party code and its license in `THIRD_PARTY_NOTICES.md`.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
